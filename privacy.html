EMAM Shorts Poster

Privacy Policy

Effective date: 9 November 2026 · Last updated: 9 November 2026

This Privacy Policy explains how EMAM Shorts Poster ("the app", "we") accesses, uses, stores, shares, protects, retains and deletes data, including data received from Google APIs (YouTube Data API v3). The app is operated by its developer, reachable at hassanmuhammad02p@gmail.com.

1. What the app does

EMAM Shorts Poster is a scheduling tool. The person who connects their accounts (the "user") prepares short vertical videos on their own computer, and the app uploads and publishes those videos, with the title and description the user wrote, to the user's own YouTube channel, Instagram professional account and Facebook Page at the times the user chooses. The app has no public sign-up and does not access the accounts of anyone who has not connected them through the sign-in screens of Google or Meta.

2. Google user data the app accesses

When the user clicks Connect YouTube, Google asks the user to grant these permissions (OAuth scopes):

  • https://www.googleapis.com/auth/youtube.upload - lets the app upload videos to the user's YouTube channel and set each video's title, description, tags, category and privacy status.
  • https://www.googleapis.com/auth/youtube.readonly - lets the app read the connected channel's ID and name, so the user can confirm the right channel is connected.

From Google the app receives and keeps only:

  • an OAuth refresh token and short-lived access tokens for the scopes above;
  • the connected channel ID and channel name (shown once on screen, not stored);
  • the video ID and link YouTube returns for each uploaded video, to show the user that the post succeeded.

The app does not access the user's email address, contacts, Gmail, Drive, watch history, subscriptions, comments, analytics, payment data or any other Google data, and it never reads, changes or deletes videos it did not upload.

3. Other data the app processes

  • Meta (Instagram and Facebook): a Page access token and the IDs of the user's Facebook Page and linked Instagram professional account, used only to publish the user's videos and read back the post link.
  • Content: the video files, cover images, titles, captions and posting times the user chooses.
  • GitHub: the user's GitHub access token for the user's own repository, where the posting schedule runs.

The app does not collect data from viewers of the videos or from any other person. It has no analytics, no advertising and no tracking cookies.

4. How the data is used

Google user data is used only to provide the app's single feature: uploading the user's own videos to the user's own YouTube channel at the scheduled time, and confirming which channel is connected. It is not used for advertising, profiling, market research, credit decisions or training machine-learning models, and it is not used for any purpose other than this user-facing feature.

5. Where the data is stored and how it is protected

  • The Google refresh token, the OAuth client credentials and the Meta Page token are stored as encrypted GitHub Actions secrets in the user's own private GitHub repository. GitHub encrypts them with libsodium sealed boxes; they cannot be read back through GitHub's website or API, and they are masked in logs.
  • Tokens are sent only over HTTPS (TLS) to Google, Meta and GitHub.
  • Access tokens are held in memory only for the few minutes a posting run takes and are never written to disk.
  • Videos and the posting schedule are stored in the user's private GitHub repository.

6. Sharing and transfer

The app does not sell, rent, trade or share Google user data or any other data with third parties. Data leaves the user's computer only to reach the services it is meant for: video files and metadata are sent to YouTube, Instagram and Facebook when they are posted, and tokens, videos and the schedule are kept in the user's GitHub repository so the scheduled job can run. No person other than the user can see this data.

7. Retention and deletion

  • Tokens are kept until the user disconnects the account or deletes the secrets from the GitHub repository (Settings → Secrets and variables → Actions). Deleting them removes them permanently.
  • Video files are deleted from the GitHub repository automatically once they have been posted to every chosen platform.
  • Post records (title, time, link) are deleted automatically 45 days after posting.
  • Videos already published on YouTube stay on the user's channel, under the user's control, until the user deletes them in YouTube Studio.

To revoke the app's access to Google at any time, open Google Account → Security → Third-party apps with account access, select EMAM Shorts Poster and choose Remove access. Access for Meta can be removed in Facebook Settings → Business Integrations. You can also email hassanmuhammad02p@gmail.com to request deletion of any stored data; requests are completed within 7 days.

8. Google API Services User Data Policy

EMAM Shorts Poster's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. YouTube API Services

The app uses YouTube API Services. By connecting a YouTube channel, the user agrees to the YouTube Terms of Service. Google's handling of personal data is described in the Google Privacy Policy.

10. Children

The app is not directed at children under 13 and does not knowingly collect data from them.

11. Changes to this policy

If this policy changes, the updated version is posted on this page with a new "Last updated" date. Material changes affecting Google user data will be made only with the user's consent.
